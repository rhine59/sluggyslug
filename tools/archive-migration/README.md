# Historical migration tools

These scripts are retained as the record of how the archive was reorganised, checked and repaired. They reference the original workspace layouts (`slugs-source`, `slugs-new`, `source`, `inventory.tsv`, etc.) and are **not** the normal rebuild path.

The `website/` snapshots preserve the current result, including later manual changes and blog links. Use `scripts/rebuild-site.py` for a current rebuild. Running the historical generator without recreating its inputs and reapplying all later patches can undo repairs or editorial changes.

No publishing scripts that require credentials or deploy automatically have been included here. The application itself does not run these tools.
