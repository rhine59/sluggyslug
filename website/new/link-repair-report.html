ARCHIVE CARE · 14 NOVEMBER 2026

Keeping the links working.

The SLUGS archive brings together decades of photographs, newsletters and club stories. Over that time, files have moved, web addresses have changed and some outside websites have disappeared. This report explains the checks and repairs made to the new archive.

2,138existing pages scanned
7,891local destinations passed
164files repaired or added

What changed?

Broken paths, malformed links and email links were corrected. We recovered 116 references to files already present in the archive. Links to missing sections within a page now lead to the existing page, rather than a section that is no longer there.

One missing gallery page—photograph 021 in the 1975 Yorkshire Dales album—was rebuilt using its existing photograph. Obsolete editor references and a missing decorative background were also removed.

What does “unavailable” mean?

If an original file or image could not be found, its place is labelled unavailable. That avoids sending you to an error page or showing a broken image. The label does not mean the historical material has been replaced or reconstructed.

Links to outside websites that returned a missing-page response or whose host could no longer be found are labelled “external site unavailable”. Their text and original addresses are retained in the page markup. Where the same address was verified to work securely over HTTPS, the link was updated.

These labels describe the result of the checks on 14 November 2026. Websites can return, move or change after that date.

What was checked?

  • All 2,138 existing HTML pages: 53,598 HTML references, plus CSS image references.
  • Local links and image references were checked against the archive files.
  • All 7,891 tested local destinations passed the final web checks, including every changed file. Initial timeouts passed on retry.
  • 606 distinct external HTTP and HTTPS addresses were tested. Inconclusive results were retained as links; five were restored following an additional check.
  • All 164 uploaded files were verified against the repaired copies.

What remains uncertain?

A timeout, certificate problem or access block does not prove that a website is gone. Those destinations remain unverified. FTP and Gopher destinations, links generated by arbitrary JavaScript and form submissions were not comprehensively tested.

This is a dated check, not continuous monitoring. A successful response confirms that a destination was reachable; it does not establish that everything on an outside website is still accurate or relevant.

The original archive is preserved.

These repairs apply only to this new copy of the site. All 10,268 files in the original site were confirmed unchanged using file checksums. A copy of the pages before repair has also been retained privately.

If this new copy is rebuilt from the originals, these repairs will need to be applied again.
