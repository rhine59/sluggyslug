<P>
This search will try six different types of search in turn until a match is
found. Alternatively the search type can be specified by writing 'LANGUAGE='
etc.
<P>The searches are
<OL>
<LI> INDEX: search for the local database index of the page.
<LI> TOPIC: search for a topic in the
<A HREF="http://www.comp.lancs.ac.uk/cgi-bin/clubs/luss/topiclist.sh?list=topic">
list</A>.
<LI> COUNTRY: search for infomation about a
<A HREF="http://www.comp.lancs.ac.uk/cgi-bin/clubs/luss/topiclist.sh?list=country">
country</A>.
<LI> LANGUAGE: search for a page of a specific
<A HREF="http://www.comp.lancs.ac.uk/cgi-bin/clubs/luss/topiclist.sh?list=language">
language</A>.
<LI> KEYWORD: search for a keyword in the title. (ie. LUSS or Lancaster)
<LI> MOUNTED: search for pages mounted in a specific country.
</OL>
